# P1 企业端核心闭环本地验收记录

> 验收日期：2026-09-02；运行方式：本地 Windows + Conda `industry_agent`；Embedding：CUDA；外部 API：未调用。

## 结论

企业端 P1 已形成可运行闭环：企业原话先经过轻量解析，用户可逐字段修改并保存不可覆盖的本地版本；只有明确确认已保存版本后，系统才按技术模块检索本地论文，经过证据闸门生成方案、技术路线、转化评估、阶段落地计划和下载文件。原始文本始终保留，用户补充内容单独标记，未知项继续进入澄清决策门。

## 已验收的数据契约

- 企业需求保留原文及逐字段证据映射；新增量化目标、测试条件、已有基础、排除路线和未解析片段。
- 技术模块只来自企业显式能力或问题，每个模块保留原文短语和确认状态。
- 每个模块独立形成检索查询，论文证据保留题名、导师、页码、Chunk、相似度和摘录。
- 方案数量由证据覆盖决定；当前证据只能支持一个方案时，不生成虚构的第二、第三方案。
- 路线以节点和边保存，包含输入、动作、输出、验收/退出口径、责任建议、风险和替代路线。
- 转化评估只让已知维度进入分母；工程成熟度和落地约束缺材料时保持未知。
- 来源类型限定为 `enterprise_confirmed`、`paper_evidence`、`system_suggestion` 和 `unknown`。
- 企业字段证据进一步区分 `enterprise_original` 与 `enterprise_user_edit`；确认快照与原文同时进入审计报告。
- 需求版本采用追加写入的 JSON 快照，记录需求 ID、父版本、状态、备注、时间和 SHA-256；内容被手工修改后加载会失败。

## 公开量化案例 GPU 验收

验收输入采用吉安市 2025 年度第二批“揭榜挂帅”榜单中江西电缆有限责任公司的“超高压线缆制造过程关键指标在线测控技术及系统”。仓库只保存带来源的结构化摘要，并在网页明确提示：公开榜单不代表本项目获得企业委托。

- 公开来源：[榜单通知与附件正文](https://www.nuochi.net/index.php?a=show&c=index&catid=79&id=1283&m=content)
- 解析结果：先进装备制造、超高压线缆在线测控系统、4 个技术模块、8 项量化指标。
- 本地 Embedding 设备：`cuda`；8 个 Agent 全部 `completed`。
- 推荐结果：徐修文，当前未校准透明匹配分 `58.59/100`；证据审查 `passed`。
- 方案：1 个；方案证据闸门 `passed`；转化决策仍为 `proceed_to_clarification`，说明论文证据通过不等于工程、知识产权、成本和现场验收信息已经齐备。
- 该结果只证明端到端软件链路可运行，不是人工专家对教师匹配或工程可行性的金标准验收。
