# 院校论文库与标签 v1 验收记录

> 日期：2026-09-02；范围：工作包 11 第一纵切；运行方式：本地 Windows + Python 3.11；外部 API：未调用。

## 1. 本轮交付

- 递归扫描本地论文目录，只接收 `.pdf`，跳过 `.venv`、`.idea`、隐藏目录和开发环境文件。
- 以 PDF 的 SHA-256 作为论文 ID，并保存“来源路径—大小—修改时间—论文 ID”缓存。
- 扩展 SQLite 论文元数据，补充院校、学院和关键词字段。
- 新增独立论文标签表，记录类别、值、来源、置信度、证据和人工审核状态。
- 自动题名规则只生成 `suggested`；只有用户操作才能形成 `confirmed` 或 `rejected`。
- 新增安全上传：大小、扩展名、PDF 文件头、加密状态、可读页数、SHA-256 和同名覆盖防护。
- 新增院校端三栏工作台：本地库/上传、搜索与分页、论文选择、元数据编辑、标签审核、Markdown 目录报告和 PDF 原文预览。

## 4. 验收与边界

- 论文列表按 SQLite 查询分页，每页 30 篇，不把 2,920 条记录一次渲染到浏览器。
- 搜索和筛选不会加载 BGE、ChromaDB 或 Moonshot 客户端。
- 大 PDF 路径直接交给本地 PDF 查看器，不把论文二进制保存到 Session State。
- PDF 在线预览依赖已安装为 `streamlit-pdf==2.0.1`。
- 论文仍未批量全文解析、切块或生成 Embedding；精读、技术路线和转化分析按钮因此保持禁用。
- 本轮未读取论文正文用于标签，也未向 Moonshot 或其他网络接口发送任何论文内容。
