# Kimi 多模态结构化精读 v1 验收记录

日期：2026-09-03

## 范围与边界

- 目标库：本地 SQLite 目录中的 2,920 篇论文、116 位导师。
- 当前具备正文输入条件：110 篇已解析/索引论文；其余论文须先完成可恢复解析。
- 默认行为：不调用外部 API，不批量发送论文。
- 单次同意范围：当前论文最多 10 个页码级原文片段、6 个公式候选、4 张提取图像，发送至 `.env` 配置的 Moonshot 接口。
- 原始 PDF、提取图像、结构化 JSON、报告和路线文件均在 `.gitignore` 中，不随正常提交上传。

## 已实现链路

1. 从解析后的图题/表题块识别图号、图注和页码。
2. 优先选择图注上方最近的 PDF 内嵌图像；没有位图时回退为矢量图页面区域。
3. 按“页码＋图号＋类型”去重，避免重复图题造成错误裁切。
4. 从非目录、参考文献和致谢 Chunk 中筛选公式候选。
5. 构造 Kimi 多模态消息：严格提示词、原文证据、公式候选和 base64 PNG。
6. 校验所有非空结论引用的 `Exx/Fxx/Qxx` 标签，拒绝不存在的来源。
7. 将图版和公式解读并入统一 Markdown 精读报告。
8. 从同一份结构化结果生成可编辑 draw.io XML，不重复调用模型。
9. 保存 `latest` 和不可覆盖的运行版本，支持网页预览与下载。

## 验收结果

- 离线单测覆盖：图像裁切、重复图号优先级、路径边界、Kimi JSON 字段、引用标签、公式候选、多模态消息格式、Markdown 持久化和 draw.io XML 可解析性。
- 真实 PDF 本地验收：《2D0D 材料的制备及可饱和吸收特性研究》检出 44 条图注候选；去重和优先级修复后，抽取的前 4 张均为实际论文图版，错误的公式区裁图已消除。
- 本轮没有向 Moonshot 发送真实论文内容。真实 Kimi 输出质量需由用户对某一篇论文明确勾选同意后再验收。

- 没有宣称 2,920 篇已全部正文解析或全部完成 Kimi 精读。
- 没有将模型自评当作图版、公式或科研结论的人工金标准。
- 扫描 PDF OCR、复杂表格数值结构化、批量任务队列、费用预算和最终 PDF 排版仍属后续工作。
