# 可携式精读报告与原公式 v2 验收记录

## 问题与根因

- 旧报告将论文图像写成 `/api/papers/.../image`，该地址只在本地 FastAPI 服务运行时有效，单独打开或发给他人的 `.md` 无法取到图片。
- 旧公式候选从大段 Chunk 中用宽松字符规则挑选，会把参考文献上标或“44 km、±10 m”性能指标误判为公式。
- 普通 Markdown 阅读器不一定安装 LaTeX 渲染器；即使模型转写正确，也可能只显示源码。

## 已完成改造

1. 从 PDF 解析结果中选择带公式编号、等号和独立版面的公式块，并按页分散取样，避免摘要指标和引文上标污染。
2. 用 PyMuPDF 从原 PDF 直接裁切高清公式 PNG；Kimi 同时接收原公式图、抽取文本和相邻符号说明。
3. 报告把公式原图、Kimi 转写、含义、适用条件和 Q 证据标签放在同一小节。原公式图是不依赖 LaTeX 插件的保底显示方式。
4. 论文图和公式图全部改用 `assets/` 相对路径，网页预览时由后端安全映射为图像接口。
5. 新增完整 ZIP 报告包，包含 Markdown、结构化 JSON、可编辑 draw.io 和全部图像资产。
6. 报告增加论文基本信息及“论文证据 / 模型解读 / 待尽调”边界，吸收长篇转化报告的证据分层优点，但不将市场、TRL 或 FTO 推断冒充论文事实。

## 真实报告迁移验收

- 已将《Ф-OTDR光纤传感系统的硬件设计与实现》旧报告原地升级，没有再次调用 Moonshot/Kimi。
- 4 张原论文图已复制到报告 `assets/`。6 张真实公式截图已生成，抽查式（2.2）、式（2.6）、式（5.1）、式（5.2）和式（5.3），无裁切、模糊或编号丢失。
- 旧 Kimi 运行已经生成的两条“定量关系”仍保留，另设“原论文公式原貌（本地补充）”，不伪装成新的 Kimi 解读。
- 全量 140 项离线回归通过；JavaScript 语法检查通过。

## 使用边界

- 双击 `.md` 如果打开的是纯文本编辑模式，仍会看到 `![...](...)` 源码，这是 Markdown 语法而非图片故障；需切换到 Markdown 预览。
- 单独复制 `.md` 而不带 `assets/` 仍会丢图，所以对外发送时优先使用 ZIP 报告包。
- 扫描型 PDF、跨多个文本块的复杂公式和公式转写准确率仍需人工抽检。
