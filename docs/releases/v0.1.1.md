# 产学研 Agent / Industry–Academia Agent v0.1.1

本版本让本地 MVP 更容易复现和安全分享：增加中英文文档、MIT 许可证、自动识别 CPU/GPU 的 Windows 安装器、跨 Conda/`.venv` 的通用启动器，以及不会与真实数据混合的完全合成示例数据。

This release makes the local MVP reproducible and safer to share.

## Highlights

- Chinese and English README files
- MIT license
- One-click Windows environment setup with CPU/GPU detection
- Portable launchers that discover Conda, `.venv`, or a compatible Python automatically
- Copyright-safe synthetic sample papers, teacher profile evidence, and enterprise request
- Sample bootstrap safety check that refuses to mix synthetic and existing real data
- Detailed Chinese and English installation guides
- Streamlit 1.62 compatibility update

## Windows first run

1. Download and extract the source archive.
2. Run `Setup-Windows.cmd`.
3. Run `Install-Sample-Data.cmd` in a fresh data environment.
4. Run `Start-Web-Demo.cmd`.

## Privacy

The release does not include API keys, real papers, enterprise requests, local vector databases, or generated teacher and matching records. All files under `examples/` are explicitly synthetic.

## Known limitations

- Real papers must be imported by an authorized user.
- PDF figures, complex tables, and scanned-page OCR are not yet interpreted.
- The app is a local single-user prototype, not a hosted multi-tenant service.
