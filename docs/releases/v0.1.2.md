# 产学研 Agent / Industry–Academia Agent v0.1.2

本版本强化论文解析、结构化切块、元数据管理和检索评测地基，为后续性能指标抽取、企业组合方案与院校论文工作台提供可靠数据层。

This release strengthens the paper-ingestion and retrieval foundation for evidence-grounded industry–academia workflows.

## Highlights

- Layout-aware PDF parsing with explicit superscript/subscript preservation
- Repeated header/footer cleanup with auditable removal statistics
- PDF table-of-contents extraction and section-aware chunks
- Standalone figure-caption and table-caption chunks
- SQLite paper catalog with SHA-256 identity, search, ingestion state, and pipeline versions
- Reviewable metadata seed file instead of Python-hardcoded paper metadata
- Backend-neutral evidence-index contract and version-isolated Chroma collection
- Offline Recall, MRR, and nDCG evaluation utilities
- Local parser/chunker audit documentation
- 67 passing offline tests

## Local validation

The authorized local three-paper validation set produced 894 `section_v2` chunks. The index was rebuilt on CUDA and a local retrieval smoke test returned traceable paper, page, and chunk identifiers. No paper excerpts were sent to Moonshot during this validation.

## Privacy

This release does not contain API keys, raw papers, local SQLite databases, vector indexes, enterprise requests, or generated evidence records. Those paths remain excluded from Git.

## Known limitations

- Retrieval metrics are implemented, but real quality claims require human-labeled qrels.
- One paper without PDF bookmarks still produces a substantial `unknown` section set.
- Figures, complex tables, scanned-page OCR, metric ontology, and hybrid retrieval remain future work.
